# 2. IMPORTANT — PRESERVE EXISTING JAVASCRIPT LOGIC

This is extremely important.

The existing website already contains JavaScript logic for things such as:

* calculators
* converters
* digital communication calculations
* input processing
* output generation
* interactive functionality

**Do NOT rewrite the mathematical/business logic unnecessarily.**

The existing JavaScript logic should be preserved and adapted into React-compatible functions.

For example, if the existing code has:

```javascript
function calculateSomething(input) {
    // existing calculation
}
```

convert it conceptually into:

```javascript
const calculateSomething = (input) => {
    // preserve the same calculation logic
};
```

Then connect it to React state:

```javascript
const [input, setInput] = useState("");
const [result, setResult] = useState(null);
```

The goal is:

**Same calculation → React state → React UI**

NOT:

**New calculation → different result**

The existing mathematical behavior must remain functionally equivalent.

# 8. CALCULATORS

This is one of the most important parts.

Find every calculator currently implemented in the original JavaScript.

For each calculator:

1. Preserve the original formula.
2. Preserve input types.
3. Preserve validation.
4. Preserve output.
5. Preserve units.
6. Preserve error handling.
7. Preserve decimal/rounding behavior unless there is an obvious bug.
8. Move state management into React.
9. Keep calculation logic separate from presentation.

Preferred pattern:

```text
UI Component
      ↓
React State
      ↓
Calculation Function
      ↓
Result
      ↓
React UI
```

Example:

```javascript
function calculateDataRate(input) {
    // Existing calculation logic
}
```

Then:

```jsx
const handleCalculate = () => {
    const result = calculateDataRate(input);
    setResult(result);
};
```

Do not put complex mathematical logic directly inside JSX.

# 20. IMPORTANT VANILLA JS MIGRATION RULE

Whenever you encounter code such as:

```javascript
document.getElementById("result").innerText = result;
```

convert it to React state:

```javascript
setResult(result);
```

Whenever you encounter:

```javascript
element.addEventListener(...)
```

convert it to React event handlers:

```jsx
onClick={handleClick}
```

Whenever you encounter:

```javascript
input.value
```

use controlled React state where appropriate:

```jsx
value={input}
onChange={(e) => setInput(e.target.value)}
```

Whenever you encounter dynamically created DOM:

```javascript
document.createElement(...)
```

prefer React rendering.
